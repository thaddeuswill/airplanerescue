# Credits

Game by thaddeuswill. Built with [Godot Engine](https://godotengine.org) (MIT license).

Plane model: Piper J-3 Cub for FlightGear by Don Lavelle (model), David Megginson and Jim Wilson, GPLv3 ([source](https://github.com/wlbragg/J3Cub)). Converted for this game; the original files and license are in `models_raw/j3cub_fg/`.
