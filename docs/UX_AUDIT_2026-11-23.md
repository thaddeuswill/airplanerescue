# UX and typography audit: every pop-up and menu changed since the process began (U1)

Iteration 18, 2026-11-23. Each screen was audited from a 1280x720 screenshot (the full-rescue
screenshot run, `--walk-shot` and `--tutorial-shot`) against the ux-laws numbers and the anti-AI
typography checklist. Sizes come from the code (`Style` sizes: 13, 15, 18, 22, 28, 36, 44).
Faces throughout are the project's chosen system (Big Shoulders Display, Courier Prime for
figures, DejaVu Serif Condensed for long reading; all OFL), so the type findings are about how
they are set, not which faces. The end-of-mission ticket was audited in iteration 17 and is not
repeated.

Paper sheets share one row style: first line 18 px, the lines under it 15 px. Many findings below
come from that one style, so one fix moves many screens.

## Top fixes across all screens

1. **The catalog still says "arrives in 1 day"** (catalog 1). A D2 defect; one line, plus extending
   the no-days check to the catalog so it can't come back.
2. **One message at a time at the top** (cockpit 2, notes 3, pause 1). Clear the message band and
   banners when a sheet, the cockpit or the pause opens. Removes the most clutter on the most
   screens.
3. **Values bigger than labels** (ending 1, wallet 1, badge board 2). The paper-sheet row style
   puts the label large and the figure small; flip it where the row is a stat.
4. **One money format** (calls 2, wallet 3, ending 4). `_thousands` everywhere money is shown.
5. **The cockpit card's cut-off foot line** (cockpit 1). A visible bug on every run-up.
