# A task list with states (P3)

**Status**: built, iteration 7
**Date**: 2026-11-23
**Code**: `main.task_list`, `_open_tasks`, `TASK_STATES`; key `tasks` (T); icons `textures/hud/task_*.svg`

## Why

Beyond the apprenticeship nothing summed up a job: what's done, what failed, what to try again.
With many tasks the player has to remember it all.

## What

- T (rebindable), and a fifth pocket by the others, opens the job's task list on paper.
- Built from what you know (`task_list`): the walk-around (N of 8), each written-up fault, each
  thing heard but not tracked down (named by its next test, never its cause), the run-up, the cowl
  if open, parking if in the hangar, fuel, the logbook, flying it out.
- Four states, each with a symbol and its word: **Done** (green check), **Can't be done** (red
  cross: no field fix, ground it), **Try again** (yellow flag: a wrong call on a trail, the wrong
  suspect swapped, a part broken by running it unready, a run-up that wouldn't start, a logbook
  entry sent back), **To do** (grey question mark).
- On demand, so it takes no screen. Its first-time walkthrough explains the symbols.
- Reads the job only. Wrong verdicts are counted per fault (`job.misses`) for the Try again state.

## Acceptance

- Self-test check 73: a job built with all four states lists each correctly; a fault you haven't
  found never appears; T opens the sheet.
